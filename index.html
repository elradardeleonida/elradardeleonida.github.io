Sobre esta web

El Radar de Leonida es un canal independiente, sin relación con Rockstar Games ni Take-Two Interactive. Grand Theft Auto es una marca de sus respectivos propietarios.

El canal usa una herramienta propia para subir y programar sus vídeos en YouTube, Instagram y TikTok mediante las API oficiales de cada plataforma.
